# fullstack_developer_capstone

**Repository name:** xrwvm-fullstack_developer_capstone
**Project name:** Best Cars Dealership – Full Stack Application Development Capstone

A dealership review web app. Users browse dealerships across the US, filter by state, read reviews, and post their own reviews with automatic sentiment analysis.

**Tech stack:** Django + React front-end, Node.js/Express + MongoDB backend (Docker), Flask sentiment analyzer on IBM Code Engine, GitHub Actions linting, Docker + Kubernetes deployment.
